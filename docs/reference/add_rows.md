# Add SNPs to ensure same SNPs are present in both samples for a replicate analysis.

Add SNPs to ensure same SNPs are present in both samples for a replicate
analysis.

## Usage

``` r
add_rows(df1, df2)
```

## Arguments

- df1:

  Data frame of the sample with the higher number of SNPs (rows)

- df2:

  Data frame of the sample with the smaller number of SNPs (rows)
