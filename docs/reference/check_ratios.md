# Check the mixture ratios for potentially single source samples (or samples with very high mixture ratios)

Check the mixture ratios for potentially single source samples (or
samples with very high mixture ratios)

## Usage

``` r
check_ratios(df, uncond = FALSE)
```

## Arguments

- df:

  dataframe of mixture ratios computed by EFM

- uncond:

  TRUE/FALSE if unconditioned analysis

## Value

message
