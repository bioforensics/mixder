# Adds additional columns if necessary to data frame to ensure same number of columns between sample and replicate

Adds additional columns if necessary to data frame to ensure same number
of columns between sample and replicate

## Usage

``` r
check_3_or_4_col(larger_df, smaller_df)
```

## Arguments

- larger_df:

  The larger of the two data frames

- smaller_df:

  The smaller of the two data frames

## Value

Data frame
