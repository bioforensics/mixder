# Kintelligence SNP positions file

Contains the hg19 SNP positions for 10,230 SNPs necessary for creating
GEDmatch PRO reports.

## Usage

``` r
kintelligence_snp_positions
```

## Format

A data frame containing 10,230 rows and 3 variables:

- rsid:

  SNP rsID

- chromosome:

  Chromosome

- position:

  Position

## Source

Verogen UAS Kintelligence Sample Report
