# Checks EFM predicted genotypes for errors

Checks EFM predicted genotypes for errors

## Usage

``` r
check_allele_probabilities(data, i)
```

## Arguments

- data:

  EFM predicted genotypes

- i:

  Set number

## Value

TRUE/FALSE

## Functions

- `check_allele_probabilities()`: function checks that the C1 predicted
  genotypes have higher allele probabilities than the C2 predicted
  genotypes.
