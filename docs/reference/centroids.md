# Centroid Calculations and Plotting

Centroid Calculations and Plotting

## Usage

``` r
centroids(groups, pca, inpath, ID)
```

## Arguments

- groups:

  Groups used for PCA (Superpopulations and/or Subpopulations)

- pca:

  dataframe of PCs and ancestry

- inpath:

  input path

- ID:

  ID for creating file name(s)
