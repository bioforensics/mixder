# Calculate the analytical threshold

Calculate the analytical threshold

## Usage

``` r
calculate_at(sample, kinreports, dynamicAT, staticAT)
```

## Arguments

- sample:

  Sample ID

- kinreports:

  Path of directory containing Kintelligence Sample Reports

- dynamicAT:

  Dynamic analytical threshold (AT)

- staticAT:

  Static analytical threshold (AT)

## Value

data frame containing SNPs and AT values
