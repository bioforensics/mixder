# Write metrics tables

Write metrics tables

## Usage

``` r
write_tables(x, outfile, minimum_snps)
```

## Arguments

- x:

  List containing a compiled metrics table of all allele 1 probability
  thresholds and a table containing metrics for the minimum number of
  SNPs.

- outfile:

  Character string containing the sample ID

- minimum_snps:

  Minimum number of SNPs required.
