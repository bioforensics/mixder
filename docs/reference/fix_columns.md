# Identifies if one sample has more columns than another; adds columns as needed.

Identifies if one sample has more columns than another; adds columns as
needed.

## Usage

``` r
fix_columns(df1, df2)
```

## Arguments

- df1:

  Data frame containing sample ID called genotypes

- df2:

  Data frame containing replicate ID called genotypes

## Value

list of data frames containing equal number of columns
