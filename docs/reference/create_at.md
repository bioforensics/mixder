# Create AT table containing only SNPs contained in the evidence file

Create AT table containing only SNPs contained in the evidence file

## Usage

``` r
create_at(evidData, sample, replicate_id, attable)
```

## Arguments

- evidData:

  Evidence data frame

- sample:

  Sample ID

- replicate_id:

  Replicate ID if provided

- attable:

  Data frame containing AT for all SNPs

## Value

Data frame
