# Allele Frequency file using 1000G Phase 3 dataset

Allele frequencies for 10,039 SNPs

## Usage

``` r
popFreq_1000G
```

## Format

A list containing a 10039 elements (SNPs) with 4 rows:

- SNP:

  SNP rsID

- Allele:

  Allele (A/C/G/T)

- Probability:

  Allele Probability

## Source

1000 Genomes (https://www.internationalgenome.org/data)
