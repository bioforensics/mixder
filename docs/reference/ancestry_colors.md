# Colors for creating 3D PCA plots

Used to run PCA for ancestry prediction

## Usage

``` r
ancestry_colors
```

## Format

A dataframe containing 5 columns and 2,506 rows:

- id:

  1000 Genome Sample ID

- reg:

  Superpopulation of Sample

- population:

  Subpopulation of Sample

- color:

  color for subpopulation

- superpop_color:

  color for superpopulation

## Source

1000 Genomes (https://www.internationalgenome.org/data)
