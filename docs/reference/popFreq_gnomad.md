# Allele Frequency file using gnomADv4 dataset

Allele frequencies for 10,039 SNPs

## Usage

``` r
popFreq_gnomad
```

## Format

A list containing a 10039 elements (SNPs) with 4 rows:

- SNP:

  SNP rsID

- Allele:

  Allele (A/C/G/T)

- Probability:

  Allele Probability

## Source

gnomAD v4 genomes (https://gnomad.broadinstitute.org/downloads#v4)
