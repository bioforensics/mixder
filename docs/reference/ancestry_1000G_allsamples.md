# 1000 Genomes genotypes for 10,030 autosomal SNPs for all 2,504 1000G samples

Used to run PCA for ancestry prediction

## Usage

``` r
ancestry_1000G_allsamples
```

## Format

A dataframe containing 10,030 columns (each SNP) and 2,504 rows (each
individual):

- SNP:

  SNP rsID with reference allele

- ID:

  Sample ID of individual

## Source

1000 Genomes (https://www.internationalgenome.org/data)
