# Creating SNP sets from evidence samples containing all SNPs

Creating SNP sets from evidence samples containing all SNPs

## Usage

``` r
create_evid_all(inpath, id, nsets, keep_bins)
```

## Arguments

- inpath:

  input path

- id:

  Sample ID

- nsets:

  number of SNP sets to create

- keep_bins:

  To use existing SNP bins or create new bins (and files)
